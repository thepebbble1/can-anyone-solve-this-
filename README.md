# Can Anyone Solve This?

A public challenge board for developers who enjoy solving real engineering problems.

The challenges here are **small, self-contained, synthetic reproductions** of bugs and design problems. They are intentionally stripped of private source code, credentials, proprietary algorithms, user data, and production secrets.

## How it works

1. Pick an open challenge.
2. Reproduce the problem using the supplied toy example or acceptance criteria.
3. Propose a fix with a pull request or explain your approach in the issue.
4. Include tests when possible.
5. Explain tradeoffs so other developers can learn from the solution.

## What kinds of challenges show up here?

Expect problems involving Python, Windows, PowerShell, packaging, installers, process cleanup, SQLite, CI/CD, test harnesses, reliability, performance, and UI/state handling.

Some challenges are quick puzzles. Others may need deeper debugging or a clever design change.

## Want to help?

Open the **Issues** tab and look for a numbered challenge. You do not need access to any private project to participate.

Useful contributions include:

- a working pull request,
- a smaller or cleaner reproduction,
- a failing regression test,
- an explanation of the root cause,
- an alternative implementation,
- platform-specific testing results.

## Ground rules

Keep solutions focused on the synthetic problem in this repository. Do not request private source code, credentials, account information, production secrets, or access to unrelated private systems.

Community solutions are an **extra parallel engineering lane**, not a dependency. The private project that inspired a challenge continues being repaired independently and never waits for this repository.

## Current challenges

See the open Issues list. New safe challenges will be added when useful engineering problems can be reduced to standalone reproductions.

If you like debugging things other people could not solve, this repo is for you.
