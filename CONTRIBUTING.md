# Contributing

Thanks for helping solve a challenge.

## Best way to contribute

1. Choose an open challenge in Issues.
2. Keep your work limited to the synthetic problem described there.
3. Add or improve a regression test when possible.
4. Submit a pull request with a short explanation of the root cause and why your fix works.
5. Mention any tradeoffs, platform limitations, or assumptions.

## Good submissions

A useful solution should be reproducible, focused, and easy to review. Prefer small changes over unrelated rewrites.

## Safety and privacy

Do not ask for or submit private source code, credentials, API keys, account identifiers, personal information, production logs, private endpoints, or proprietary trading/security logic.

Challenges in this repository are intentionally standalone. A solution should not need access to any private repository or production service.

## Licensing and attribution

Only submit work you have the right to contribute. If your solution incorporates third-party code, libraries, or substantial ideas with licensing requirements, identify them clearly in the pull request.
